# Personal Portfolio Website – Assignment 02

A personal portfolio website built with **Node.js**, **ExpressJS**, and the **EJS** templating engine, hosted live on **Render**.

* **Live Portfolio Website:** https://david-abati-portfolio.onrender.com

## Project Structure
* **`routes/index.js`**: Defines Express routes for the Home, About Me, Projects, and Contact Me pages.
* **`views/`**: Contains the EJS page templates (`index.ejs`, `about.ejs`, `projects.ejs`, `contact.ejs`) and shared layout partials (`views/partials/`).
* **`public/Assets/`**: Stores organized CSS stylesheets, client-side JavaScript, images, and videos.
* **`app.js` & `server.js`**: Configures Express middleware, static folders, the EJS view engine, and the server port.

## Frameworks & External Libraries Cited
 The following open-source frameworks and libraries were used:
* **ExpressJS & Express Generator** (`https://expressjs.com`): Web framework and project scaffolding with EJS support.
* **EJS (Embedded JavaScript)**: Templating engine used for dynamic views and shared header/footer partials.
* **Bootstrap 5** (`https://getbootstrap.com`): Responsive layout grid, navigation bar, and UI styling.
* **Font Awesome** (`https://fontawesome.com`): Icons used across the navigation bar and footer social links.
